How to add materials

Materials live in this site's GitHub repository. To add a file, open the materials folder in the repo, choose a subject folder (or create one), and use GitHub's "Add file → Upload files" button. The site updates automatically — no coding needed.

Free hosting

This page is built to run on GitHub Pages at no cost. Anyone with the repo link can browse; anyone you invite as a collaborator can upload.

About

CABD Studocu is an open catalog for course notes, past papers, slides and guides — organized by subject, always free to use.
